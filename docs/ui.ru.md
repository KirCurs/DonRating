## Экран сотрудника

Откройте `/admin`. Если включена авторизация, введите ключ сотрудника.

В разделе **«Подключить планшет»** укажите имя и создайте подключение. На планшете отсканируйте QR камерой или откройте ссылку вручную. Используйте сетевой адрес приложения, доступный планшету. В ссылке и QR содержится ключ устройства, поэтому передавайте их только сотрудникам. QR формируется в браузере. Если его не удалось создать, ссылка остаётся доступной. Исходный ключ выдаётся при создании устройства, а в PostgreSQL хранится его хеш SHA-256.

Регистрация сохраняется после перезапуска сервера. Планшет получает статус «В сети», когда начинает опрашивать API. В меню **«Планшет для оценки»** выберите устройство или оставьте список всех карточек. В карточке видны статус подключения, текущее приглашение и последний ответ. Нажмите **«Попросить оценку»**, когда планшет в сети и свободен. Сервер создаст ID приглашения и установит срок ответа.

## Экран гостя

Пример адреса — `/tablet?device_id=reception-1`. Чтобы передать ключ, один раз откройте `/tablet?device_id=reception-1#token=TABLET_KEY`. Браузер сохранит ключ и уберёт фрагмент из адресной строки. При недоступности постоянного хранилища используется хранилище вкладки. После очистки данных сайта или запуска в приватном режиме может понадобиться открыть ссылку повторно. Храните её в защищённом месте: сервер не может восстановить ключ по хешу.

В режиме ожидания планшет показывает слайды или заставку. По приглашению появляется форма с оценками от 1 до 5. После успешной отправки две секунды показывается благодарность, затем продолжается показ слайдов. Если время истекло, форма закрывается. При временной ошибке выбранная оценка сохраняется до истечения срока, чтобы её можно было отправить повторно.

Для локальной проверки удобно открыть две вкладки — сотрудника и планшета. Для работы с физического планшета настройте сетевой доступ, ключ устройства и HTTPS. Стандартная конфигурация Compose публикует приложение на loopback.

## Файлы интерфейса

В папке `internal/httpapi/web` находятся:

- `admin.html` и `admin.js` для экрана сотрудника.
- `tablet.html` и `tablet.js` для экрана гостя.
- `app.css` и `app.js` с общими стилями и функциями API.

Ресурсы встроены в бинарный файл. После изменений перезапустите `go run ./cmd/feedback` или пересоберите образ Docker. Основной интерфейс использует локальные ресурсы. У внешнего плеера могут быть собственные зависимости от CDN.

## Полноэкранный режим

Нажмите **«На весь экран»** на планшете. Слайд-шоу, форма и благодарность остаются на одной странице, поэтому переходы между ними сохраняют полноэкранный режим. Если выйти из него, кнопка появится снова.

При поддержке браузером приложение запрашивает Wake Lock, чтобы экран оставался включённым. Оно повторяет запрос, когда страница снова становится видимой. Для Wake Lock нужен защищённый контекст: HTTPS или локальный адрес, которому доверяет браузер. Для работы без оператора настройте киоск-режим браузера или ОС и параметры сна самого планшета.
